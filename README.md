# OurWord.ai

站点导航。只列真实在线、点得开的项目。

- [像素图鉴 PIXELDEX](https://woowoeth.github.io/pixelpad/) —— 输入一个词，画一张 16×16 像素图（源码在 `woowoeth/pixelpad`）
- [走你](https://woowoeth.github.io/zouni/) —— 输入去哪儿、几天、多少预算，出一份能照着走的攻略
- [Skill Store](https://woowoeth.github.io/skill-store/) —— 每天上新的 Agent Skill 精选店

单文件、零脚本、零依赖。视觉走北欧黑白风，两种配色下文字对比度均已用脚本穷举扫描过。
