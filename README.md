# OurWord.ai

面向中文读者的小工具。单文件、无依赖、打开就能用，全部计算在浏览器里完成。

- `index.html` —— 站点首页
- `pixeldex/` —— 像素图鉴 PIXELDEX：输入一个词，画一张 16×16 像素图
  - `engine.js` 图样库 + 词库匹配 + 程序生成（不碰 DOM）
  - `app.js` 画布、动画、导出、事件

## 像素图鉴怎么判词

1. 全等命中 → 直接调出手绘图样
2. 词里含收录的字词 → 取那一段画（`深夜加班` 取「加班」画电脑；中文复合词取最靠后的最长匹配）
3. 都对不上 → 由字形哈希铸一枚印记，界面上明说「它不描述这个词」

收录 45 枚逐格手绘图样。同一个词永远得到同一张图。

## 视觉

北欧黑白风：高对比黑白灰、大留白、黑色实心药丸 CTA、卡片零描边靠双层浅阴影。
整站唯一出现彩色的地方是那些 16×16 本身。

深色模式下中性阶整条翻转，但像素图自带深色描边，所以画布与缩略图始终保留一块亮版。
两种模式的文字对比度均已用脚本穷举扫描，全部过 WCAG AA。
